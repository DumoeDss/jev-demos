# Cobalt Grid assets

Design adapted from Zara Zhang's MIT-licensed Cobalt Grid template, selected by the user from the local Elftia template library.

- Source: https://github.com/zarazhangrui/beautiful-html-templates/tree/main/templates/cobalt-grid
- `pixel-stair.svg` adapts the template's scanline staircase. The original MIT notice is in `LICENSE`.
- Newsreader, Hanken Grotesk and DM Mono are bundled locally as Latin WOFF2 fonts. Their SIL Open Font Licenses are included alongside the font files; system fonts cover other scripts.
- Palette: paper `#F0EBDE`, cobalt `#1F2BE0`. The template's typography and graphic details are adapted to a responsive application workspace.
